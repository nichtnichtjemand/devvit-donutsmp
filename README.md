# A Tool for r/DonutSMP

## What it is
### This should be a Devvit App for the Reddit Subreddit r/DonutSMP where I am moderator. It is able to process vouches and reports on other users so you know who you can trust and who not.
## How it works
### If you have Devvit set up, you can just clone the repository and run `npm run dev`. It tells you some stuff, and it should get an own private test subreddit.
